## Import notes (3D artist -> engineer)
- Import all FBX with the Studio 3D Importer, File Dimensions = **Studs**, then save into ReplicatedStorage.Assets and set:
  - `Assets.Guns.<type>` (pistol, smg, shotgun, rifle, blaster, railgun): the `_r1` file as MeshPart `Handle`; `Assets.Guns.<type>_r5` = top-tier variant. Other rarities: tint via code (accent strips are emissive parts of the single mesh, so use Highlight/colour tween, or re-export with `make_gun.py --rarity N`). Anchored=false, CanCollide=false, CollisionFidelity=Box, Massless=true.
  - Gun orientation: barrel along +X (Blender/FBX), origin = grip centre. Tool.Grip = CFrame.Angles(0, math.rad(90), 0) makes the muzzle face the character's front; if it faces backwards use -90.
