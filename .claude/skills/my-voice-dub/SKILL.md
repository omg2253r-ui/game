# พากย์คลิปด้วยเสียงของฉัน

สกิลนี้ใช้เสียงของ **เจ้าของ repo เท่านั้น** (เสียงต้นแบบที่เขาอัดเอง) ห้ามใช้ทำเสียงของคนอื่น
หรือสร้างคลิปที่ทำให้คนเข้าใจผิดว่าเจ้าของเสียงพูดสิ่งที่เขาไม่ได้อนุญาต

สคริปต์: `.claude/skills/my-voice-dub/scripts/voice_dub.py` (เรียกด้วย `python <path> <คำสั่ง>`)

## 1. ติดตั้ง (ครั้งแรกของแต่ละเครื่อง/เซสชัน)

```bash
python3 -m venv ~/.voice-dub && . ~/.voice-dub/bin/activate
pip install f5-tts f5-tts-th faster-whisper soundfile
```
ต้องมี `ffmpeg` และเข้าถึง Hugging Face ได้ (huggingface.co, us.aws.cdn.hf.co) เพื่อโหลดโมเดลครั้งแรก
ในคลาวด์ใช้ environment “game (voice dubbing)” ที่เปิด host เหล่านี้ไว้แล้ว

## 2. เสียงต้นแบบ (voice/ref.wav + voice/ref.txt)

โฟลเดอร์ `voice/` ถูก gitignore ไว้ — **ไม่เก็บเสียงจริงใน repo สาธารณะ** ถ้ายังไม่มี ให้ขอคลิปเสียงผู้ใช้
(พูดภาษาไทยชัด ๆ 3–8 วินาที ไม่มีเพลง/เสียงรบกวน) แล้วรัน:

```bash
python voice_dub.py prepare-voice <คลิปเสียงฉัน.mp4|.wav|.m4a> [--text "ข้อความที่พูดจริง"]
```
ตรวจ `ref_text` ที่ได้ ถ้าถอดผิดให้รันใหม่พร้อม `--text` ที่ถูกต้อง (ข้อความต้องตรงกับเสียง ไม่งั้นเสียงเพี้ยน)
ตั้ง `MY_VOICE_DIR` เพื่อเก็บเสียงต้นแบบไว้ที่อื่นได้

## 3. พากย์คลิป

1. ถอดเสียงคลิปต้นฉบับเป็นช่วงเวลา:
   `python voice_dub.py transcribe clip.mp4 -o seg.json [--lang en]`
2. แก้ `seg.json`: ช่อง `text` = บทที่จะพากย์ (แปลเป็นไทย/เขียนใหม่ได้), `orig` = ของเดิม
   - เขียนให้ยาวพอ ๆ กับช่วง `start`–`end` (ไทยราว 6–8 พยางค์/วินาที)
   - คำอังกฤษให้เขียนเป็นคำอ่านไทย เช่น Good morning → กู๊ดมอร์นิ่ง
   - ใส่ `"speed": 0.85` รายบรรทัดได้ถ้าเสียงเร็วเกิน; `text` ว่าง = ข้ามบรรทัดนั้น
   - คลิปที่ไม่มีเสียงพูด: สร้าง seg.json เองเป็น `[{"start":0,"end":5,"text":"..."}]`
3. สร้างคลิปพากย์:
   `python voice_dub.py dub clip.mp4 seg.json -o clip_dub.mp4 [--bg 0.15] [--max-speedup 1.35]`
   - `--bg` ความดังเสียงเดิมที่คงไว้เป็นพื้นหลัง (0 = ตัดเสียงเดิมทิ้ง)
   - เสียงที่ยาวเกินช่องจะถูกเร่ง (ไม่เกิน `--max-speedup`) ถ้ายังยาวเกินให้ย่อบทแล้วรันใหม่
   - output เป็น `.wav`/`.mp3` ได้ถ้าต้องการแค่เสียง

อ่านข้อความเดี่ยว ๆ: `python voice_dub.py speak "ข้อความ" -o out.wav [--speed 0.9]`

## หมายเหตุ
- บน CPU ช้า (~1–2 นาที/ประโยค) — บอกผู้ใช้ล่วงหน้าเมื่อคลิปยาว; มี GPU จะเร็วกว่ามาก
- โมเดล: VIZINTZOR/F5-TTS-THAI (CC-BY-4.0, รองรับไทย+อังกฤษ), ถอดเสียงด้วย faster-whisper (`--whisper medium`, เปลี่ยนเป็น `large-v3` ให้แม่นขึ้น)
- ส่งไฟล์ผลลัพธ์ให้ผู้ใช้ฟังทุกครั้ง และถามว่าต้องการปรับบท/ความเร็วไหม
