# สิทธิ์ เนื้อหา และความเป็นส่วนตัว

> เอกสารนี้อธิบายว่าระบบทำงานอย่างไรในด้านกฎหมาย ไม่ใช่คำแนะนำทางกฎหมาย
> ข้อกำหนดการใช้งานและนโยบายความเป็นส่วนตัวใน `apps/web/src/content/legal.ts` เป็นฉบับร่าง
> ต้องให้ทนายตรวจก่อนเปิดใช้งานจริง (โดยเฉพาะ PDPA ของไทย และ GDPR ถ้ามีผู้ใช้ในยุโรป)

## ใครมีสิทธิ์ในโมเดลที่สร้าง

| ใคร                       | สิทธิ์                                                                                | อยู่ในระบบที่ไหน                           |
| ------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------ |
| ผู้สร้าง                  | เป็นเจ้าของ ใช้ได้ทั้งส่วนตัวและเชิงพาณิชย์                                           | ข้อกำหนดการใช้งาน, `licenseNotice()`       |
| ผู้ที่ได้ไฟล์จากลิงก์แชร์ | ใช้ส่วนตัวเท่านั้น เว้นแต่ผู้สร้างเปิด "อนุญาตให้ผู้อื่นใช้เชิงพาณิชย์"               | `models.allow_commercial_use`              |
| 3D Design                 | ไม่อ้างสิทธิ์ เก็บไฟล์เพื่อให้บริการเท่านั้น                                          | ข้อกำหนดการใช้งาน                          |
| ผู้ให้บริการ AI           | อาจมีเงื่อนไขเพิ่ม (เช่น แผนฟรีบางเจ้ากำหนดให้ระบุแหล่งที่มาหรือไม่อนุญาตเชิงพาณิชย์) | ต้องตรวจเงื่อนไขของเจ้าที่เลือกก่อนเปิดใช้ |

ข้อความสิทธิ์ถูกฝังใน GLB ทุกไฟล์ (`asset.copyright` และ `extras.license`) พร้อมรหัสโมเดลและรหัสบัญชีผู้สร้าง
เมื่อผู้สร้างเปลี่ยนการอนุญาตเชิงพาณิชย์ ไฟล์ที่เก็บไว้จะถูกเขียนข้อความสิทธิ์ใหม่ทันที (`restampLicense`)
ฟอร์แมตที่ฝังข้อความไม่ได้ (OBJ, STL) จะส่งพร้อม `LICENSE.txt` ใน ZIP ใน phase 2

## การกรองเนื้อหา

- `packages/shared/src/moderation.ts` กันชื่อตัวละครและแบรนด์ที่มีลิขสิทธิ์ (ไทย+อังกฤษ), ชิ้นส่วนอาวุธปืนที่ใช้งานได้จริงสำหรับพิมพ์ 3D,
  เนื้อหาทางเพศเกี่ยวกับผู้เยาว์ และสัญลักษณ์ความเกลียดชัง
- ตรวจทั้งคำอธิบายและ negative prompt, normalize Unicode และตัด zero-width characters ที่ใช้หลบตัวกรอง
- ทำงานสองชั้น: UI เตือนขณะพิมพ์ (ไม่เสียเครดิต) และ API บังคับ (`422 content_copyrighted / content_prohibited`)
- word list ไม่พอสำหรับการเปิดสาธารณะ ต้องเพิ่ม moderation API เชิงความหมาย (roadmap phase 2)

## ความปลอดภัยของไฟล์อัปโหลด

ตอนนี้ไฟล์ที่ผู้ใช้อัปโหลดได้มีแค่ภาพย่อที่เบราว์เซอร์สร้างเอง: จำกัด 512 KB, ต้องเป็น PNG/WebP/JPEG และ Content-Type
ต้องตรงกับ magic bytes (`sniffImage`) — SVG และไฟล์ปลอมนามสกุลถูกปฏิเสธ
Image-to-3D (phase 3) จะใช้ฟังก์ชันเดียวกัน + สแกน ClamAV + ลบ EXIF ก่อนส่งให้ผู้ให้บริการ

## ความเป็นส่วนตัว

- คุกกี้เดียว `d3_sid` (httpOnly, SameSite=Lax, Secure ใน production) ไม่มีตัวติดตามบุคคลที่สาม ฟอนต์ self-host
- IP ใช้กับ rate limit ในหน่วยความจำ/Redis (หมดอายุใน 60 วินาที) ไม่ถูกเขียนลงฐานข้อมูล
- หน้าแชร์ไม่แสดงคำอธิบาย seed หรือรหัสบัญชี; การลบโมเดลลบไฟล์และภาพย่อออกจาก storage ทันที
- คำอธิบายถูกส่งไปผู้ให้บริการ AI ที่ตั้งค่าไว้ ต้องระบุชื่อผู้ให้บริการในนโยบายจริง
