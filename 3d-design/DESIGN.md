# DESIGN.md — 3D Design

เอกสารนี้คือ design plan ที่เขียนก่อนลงมือโค้ด และถูกแก้หลังตรวจเทียบกับ brief
ทุก token ที่อ้างถึงอยู่ใน `apps/web/src/styles/tokens.css` ที่เดียว

---

## 1. แนวคิด: โต๊ะปั้นในสตูดิโอ

ผู้ใช้ไม่ได้ "สั่ง AI" แต่กำลังปั้นงานบนโต๊ะหมุน (banding wheel) ของช่างปั้น
รอบโต๊ะคือถาดเครื่องมือ ซ้ายคือดินกับแบบร่าง (คำอธิบาย สไตล์ คุณภาพ)
ขวาคือเครื่องมือวัดและกล่องส่งของ (สถิติ mesh, ความเข้ากันได้, ดาวน์โหลด)

ภาพที่ใช้เป็นตัวตั้ง

- ฉากหลังกระดาษเทาแบบถ่ายสินค้า (grey sweep) ที่ทำให้สีของวัสดุอ่านได้ตรง
- ตลับเมตรสีเหลือง เครื่องมือวัดที่มีอยู่ในทุกเวิร์กช็อป
- ดินเหนียวสีเทาที่ยังไม่เผา เป็นสถานะ "กำลังปั้น" ระหว่างรอผล
- โต๊ะหมุนที่มีขีดองศารอบขอบ

## 2. Palette

โหมดมืดเป็นหลัก 6 สีหลัก แต่ละสีมีบทบาทเดียว

| ชื่อ                       | Hex (มืด) | Hex (สว่าง)                             | บทบาท                                            |
| -------------------------- | --------- | --------------------------------------- | ------------------------------------------------ |
| Graphite — ผนังสตูดิโอ     | `#131517` | `#ECE9E3`                               | `--bg` พื้นหลังแอป                               |
| Workbench — โต๊ะทำงาน      | `#1C1F22` | `#F7F5F1`                               | `--surface` ถาดเครื่องมือซ้าย/ขวา, header        |
| Plaster — ปูนปลาสเตอร์     | `#ECE7DD` | `#1B1D1F`                               | `--text` ตัวอักษรหลัก                            |
| Tape yellow — ตลับเมตร     | `#F2C230` | `#F2C230` (พื้น) / `#7A5C00` (ตัวอักษร) | `--accent` การกระทำหลัก, เส้นวัดขนาด, focus ring |
| Kiln red — เตาเผา          | `#F0675C` | `#B42318`                               | `--danger` ลบ, error                             |
| Grey sweep — ฉากถ่ายสินค้า | `#34383C` | `#C9C6C0`                               | `--viewer` พื้นหลังของ viewer เท่านั้น           |

สีรอง (tints ที่คำนวณจากสีหลัก ไม่ใช่สีใหม่): `--surface-2` ช่องกรอก/ปุ่มรอง,
`--line` เส้นแบ่ง, `--text-muted` ข้อความรอง, `--ok` (เขียวคราบสนิมทองแดง) ใช้กับเครื่องหมาย "พร้อมใช้" เท่านั้น

กฎการใช้สี

- เหลืองปรากฏได้แค่ 3 ที่: ปุ่มการกระทำถัดไป (1 ปุ่มต่อหน้าจอ), เส้น/ตัวเลขวัดขนาดบนโมเดล, focus ring
- ในโหมดสว่าง เหลืองใช้เป็น "พื้น" ได้ (ตัวอักษรดำบนเหลือง) แต่ตัวอักษรหรือเส้นสีเหลืองบนพื้นสว่างใช้ `--accent-ink` แทน เพราะเหลืองบนขาวไม่ผ่าน AA
- ไม่มี gradient ตกแต่ง สีสันในหน้าจอมาจากตัวโมเดลเท่านั้น

Contrast ตรวจด้วย `pnpm --filter @3d-design/web contrast` ซึ่งอ่านค่าจาก `tokens.css` โดยตรง ทุกคู่ผ่าน WCAG AA ทั้งสองธีม (ตารางผลอยู่ใน [docs/critique.md](docs/critique.md#contrast))

## 3. Typography

| ตระกูล                 | บทบาท                                                                  | น้ำหนัก       |
| ---------------------- | ---------------------------------------------------------------------- | ------------- |
| **IBM Plex Sans Thai** | ทุกข้อความใน UI ทั้งไทยและอังกฤษ (มี Latin ในตัว)                      | 400, 500, 600 |
| **IBM Plex Mono**      | ตัวเลขที่เป็นการวัด: จำนวนสามเหลี่ยม, ขนาดไฟล์, ขนาดจริง, seed, เครดิต | 400, 500      |

เหตุผล: ตระกูล Plex ถูกออกแบบจากมรดกเครื่องจักรอุตสาหกรรมของ IBM ให้ความรู้สึก "เครื่องมือ"
แต่ยังอ่านง่าย ส่วน Plex Sans Thai มีหัวกลมชัดและออกแบบมาคู่กับ Latin ทำให้ข้อความผสมไทย-อังกฤษ
(เช่น "ดาวน์โหลด GLB") ไม่สะดุด ตัว Mono ทำให้ตัวเลขเรียงตรงหลักเหมือนหน้าปัดเวอร์เนียร์

ฟอนต์ self-host ผ่าน `@fontsource` ไม่เรียก Google Fonts (ไม่ส่ง IP ผู้ใช้ไปบุคคลที่สาม)

Type scale (px / line-height) — ภาษาไทยมีสระบน-ล่าง จึงใช้ line-height สูงกว่าปกติ

| Token          | ขนาด             | ใช้กับ                   |
| -------------- | ---------------- | ------------------------ |
| `text-display` | 40 / 52, 600     | หัวเรื่องหน้าแรกเท่านั้น |
| `text-h1`      | 28 / 40, 600     | หัวเรื่องหน้า            |
| `text-h2`      | 20 / 30, 600     | หัวข้อในแผง              |
| `text-body`    | 16 / 26, 400     | เนื้อหา, ช่องกรอก        |
| `text-small`   | 14 / 22, 400–500 | ป้ายกำกับ, ปุ่ม          |
| `text-caption` | 12 / 18, 400     | คำอธิบายรอง, หน่วย       |

- ความยาวบรรทัดของย่อหน้าจำกัดที่ `max-w-prose` = 68ch
- ไม่มี `text-transform: uppercase` ในระบบ ป้ายกำกับเป็น sentence case เสมอ
- ตัวเลขใช้ `tabular-nums`

## 4. Spacing, radius, shadow, z-index

- **8px grid**: Tailwind `--spacing` ตั้งเป็น `8px` ดังนั้น `p-1` = 8px, `p-2` = 16px, `gap-3` = 24px
  ค่าครึ่งขั้น (`p-0.5` = 4px) ใช้ได้เฉพาะภายในคอนโทรล (เช่น ระยะไอคอนกับข้อความ)
- **Radius ตามลำดับชั้น** (ไม่ใช่ค่าเดียวทั้งแอป)

  | Token             | ค่า   | ใช้กับ                                              |
  | ----------------- | ----- | --------------------------------------------------- |
  | `rounded-none`    | 0     | ถาดเครื่องมือ (panel), header — ชิดขอบเหมือนชั้นวาง |
  | `rounded-control` | 4px   | ปุ่ม, ช่องกรอก, segmented control                   |
  | `rounded-tile`    | 6px   | ภาพย่อใน library                                    |
  | `rounded-overlay` | 10px  | modal, toast — สิ่งที่ลอยอยู่เหนือหน้า              |
  | `rounded-pill`    | 999px | ป้ายแท็ก, ยอดเครดิต                                 |

- **Shadow มีระดับเดียว** `shadow-overlay` สำหรับสิ่งที่ลอย (modal, toast) เท่านั้น
  panel ไม่มีเงา แบ่งด้วยเส้น 1px; แสงและเงาจริงเป็นของโมเดลใน viewer
- **z-index** `--z-viewer-ui: 10`, `--z-header: 20`, `--z-modal: 40`, `--z-toast: 50`

## 6. หลักการออกแบบ

1. **โต๊ะหมุนคือพระเอก ที่เหลือคือถาดเครื่องมือ**
   viewer เป็นพื้นผิวเดียวที่มีแสง เงา และสีสัน แผงซ้ายขวาเป็นถาดเรียบสีกราไฟต์ชิดขอบ
   ไม่มีการ์ดลอย ไม่มีภาพประกอบ จุดเด่นของหน้ามีจุดเดียวเสมอ
2. **อ่านเหมือนเครื่องมือวัด**
   ตัวเลขทุกตัวมีหน่วย ใช้ฟอนต์ mono และบอกค่าจริง (สามเหลี่ยม, KB, เมตร, เครดิต)
   เส้นวัดขนาดบนโมเดลเป็นสีเหลืองตลับเมตร ราคาเครดิตอยู่บนปุ่มและใน dialog ก่อนกดเสมอ
3. **สีมาจากวัสดุ ไม่ใช่การตกแต่ง**
   โครงหน้าจอเป็นสีกลาง สีสันมาจากโมเดลเท่านั้น เหลืองแปลว่า "สิ่งที่ควรทำต่อ" หรือ "การวัด"
   แดงแปลว่า "ลบหรือผิดพลาด" ไม่มีความหมายอื่น

## 7. Motion

- **Page-load sequence เดียว** (240ms รวม): แผงซ้ายและขวาเลื่อนเข้า 8px + opacity, โต๊ะหมุนตามมาหลัง 60ms
  ใช้ class `.enter` ใน `index.css` ครั้งเดียวต่อการโหลดหน้า
- **Motion ที่ตอบสนองการกระทำ**: เปิด modal (scale 0.98 → 1, 160ms), toast เข้า (120ms),
  disclosure "ตัวเลือกขั้นสูง" กาง, แถบความคืบหน้า, โต๊ะหมุนหมุนช้าๆ เมื่อผู้ใช้ไม่ได้จับ
- **ไม่มี** fade-in ตาม scroll, ไม่มี hover animation บนการ์ด
- `prefers-reduced-motion: reduce` ปิด transition ทั้งหมด, ปิดการหมุนอัตโนมัติ, ปิด damping ของกล้อง
  และก้อนดินระหว่างรอผลไม่ "หายใจ"
